## 🤔 为什么需要「说AI懂的话」？

你用 ChatGPT、DeepSeek、Kimi 的时候，是不是经常这样：

**你的输入：**
> "帮我看看那个项目最近有没有啥问题，就是上次说的那个，你懂的"

**AI 回复：**
> "请问您指的是哪个项目？能提供更多细节吗？"

问题不在 AI —— 在于**你说话太「人」了**。AI 需要清晰、有上下文、有约束条件的指令。但普通人没时间也没必要去学 Prompt 工程。

**「说AI懂的话」就是帮你做这件事：你用人话表达想法 → 它翻译成 AI 能精确执行的专业指令。**

## 🚀 用户使用指南

### 一、安装说明

#### Mac 版
1. 先看电脑芯片：左上角  → 关于本机 → 芯片
   - **Apple 芯片**（M1 / M2 / M3 等）→ 下载 `sayai-mac-arm64.zip`
   - **Intel 芯片** → 下载 `sayai-mac-x64.zip`
2. 双击解压 → 把 `说AI懂的话.app` 拖到「应用程序」文件夹
3. 第一次打开：**右键点击** App 图标 → 选择「打开」→ 弹出提示后点「打开」
4. 如果仍提示“无法打开”或“已损坏”：先右键 App 选择「打开」。如果仍被系统拦截，打开「终端」，输入下面命令后回车，再打开 App：
   `xattr -dr com.apple.quarantine "/Applications/说AI懂的话.app"`
5. 语音权限提示 → 点「允许」

#### Windows 版
1. 下载 `sayai-win-v2.zip` → 右键解压
2. 双击 `说AI懂的话.exe` 直接运行
3. 首次打开可能被 Windows Defender 拦截 → 点击「更多信息」→ 「仍要运行」

---

### 二、功能使用说明

#### 1. 基础翻译（白话→AI指令）
1. 在上方输入框输入你的需求（越具体越好）
2. 点「翻译」按钮
3. 系统返回 **A / B / C 三个版本**，每个版本风格不同
4. 点击任一版本即可**复制**到剪贴板
5. 打开 ChatGPT / DeepSeek / Kimi 任意 AI → 粘贴 → 发送

**技巧：** 输入时包含"写给谁看、什么用途、什么风格"效果更好
> 例：*"帮我写一段微信朋友圈卖手工皂的文案，目标客户是25-35岁女性，要有情感共鸣"*

#### 2. 语音输入
1. 点击 🎤 **麦克风按钮**
2. 对着麦克风说话（说完了等一下）
3. 再点一下麦克风按钮停止录音
4. 识别出的文字会自动填入输入框 → 点「翻译」即可

#### 3. 记忆本
- 翻译结果点「复制」后，系统自动记住这次的原文
- 下次输入类似场景，AI 会参考你的历史偏好
- 不需要手动管理，完全自动

#### 4. 更新
- 顶部出现黄色提示条 → 点击「更新」
- 系统自动下载 → 替换 → 重启 → 完成
- 全程不需要手动操作
